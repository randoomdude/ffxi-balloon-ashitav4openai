# Balloon 4.3.2 Cinematic 1

This pre-release updates cinematic controls so restoring native chat with Escape or `/` can be followed by `/balloon cinematic on` again in the same event. It also retains the dialogue balloon during native advance attempts, removes repeated keyboard-focus grabbing and restores native access when hiding cannot be maintained safely.

## Install or update

Download **balloon-4.3.2-cinematic.1.zip** below. Unload Balloon, back up the existing `addons/balloon` folder, then extract the ZIP into your Ashita `addons` directory. The archive includes themes, portraits and the pinned gdifonts library. Keep your existing `config/addons/balloon` directory.

```text
/addon load balloon
/balloon 2
/balloon cinematic on
```

For an already loaded addon, use `/addon reload balloon` once after updating. Escape or `/` restores the native chat; `/balloon cinematic on` re-enables hiding without another reload.

`/balloon 2` preserves full NPC dialogue in native chat. `/balloon 1` replaces that copy with abbreviated placeholders. Both modes can use cinematic hiding.

## Validation

Offline LuaJIT regression checks passed for repeat advance, choices, typing, Escape/slash recovery and repeated re-enabling. The ZIP was checked for required files and complete dependency inclusion. Broader in-game cutscene behavior remains unverified, so this is published as a pre-release.
